# Functional And System Requirements

Stable identifiers in this file must not be renumbered. Unless a row says otherwise, failures return a localized validation, authentication, authorization, not-found, conflict, or safe unexpected-error response without partial writes. Cross-cutting security, accessibility, localization, performance, and test expectations are defined in `docs/non-functional-requirements.md` and apply to every requirement.

Status values are `implemented`, `implemented and verified`, `partially implemented`, `blocked by external dependency`, and `not applicable with documented reason`.
