# Non-Functional Requirements

These requirements apply to every functional requirement unless a narrower rule explicitly applies. “Verified” means the listed automated or manual check has actually passed against the current code.

| ID                      | Verifiable requirement                                                                                                                                                                                                                      | Security / data / localization / accessibility / performance implications                             | Implementation and verification                                                           | Status                                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `sec-auth-001`          | Authentication, password reset, verification, passkey, two-factor, and password-confirmation flows use Fortify controls, regenerate/invalidate sessions correctly, and apply bounded rate limits without account enumeration.               | Protects identity and session state; user messages are localized and safe.                            | Fortify provider/config and auth feature tests                                            | Implemented and verified                                                                                                           |
| `sec-data-001`          | Every workspace-owned query and identifier is scoped through an authorized workspace or parent aggregate; mixed/foreign sets fail atomically.                                                                                               | Prevents horizontal privilege escalation and tenant leakage.                                          | Policies, Form Requests, actions, scoped query objects; cross-workspace feature/API tests | Implemented and verified                                                                                                           |
| `sec-token-001`         | Secrets and one-time tokens are cryptographically random where created, stored as digests when lookup permits, expiring, single-use, replay protected, redacted from logs, and rate limited.                                                | Covers invitations, password reset, verification, API credentials, and session material.              | Invitation/auth implementations and tests; log review                                     | Implemented and verified                                                                                                           |
| `sec-upload-001`        | Uploaded content is bounded by size, real MIME/type pair, dimensions where relevant, safe generated names, configured private disks, and authorized download/delete.                                                                        | Prevents spoofing, traversal, public exposure, and orphaned partial writes.                           | Avatar/attachment/import requests/actions and feature tests                               | Implemented and verified                                                                                                           |
| `sec-backup-001`        | Backup/restore uses owner authorization, password confirmation for restore, opaque identifiers, SQLite-consistent snapshots, integrity checks, locking, private storage, rollback, and path containment.                                    | Protects the full data store from disclosure/corruption.                                              | Backup policy/service/actions and isolated database tests                                 | Implemented and verified                                                                                                           |
| `sec-web-001`           | CSRF/origin protections, safe redirects, escaped output, explicit rich-HTML boundaries, and non-disclosing production exceptions remain enabled.                                                                                            | Applies to all browser endpoints and presentation.                                                    | Laravel middleware/bootstrap, Blade architecture tests, auth/security tests               | Implemented and verified                                                                                                           |
| `sec-deps-001`          | Production and development dependencies have no known actionable security advisory at delivery; unavoidable findings identify package, advisory, affected requirement, and external blocker.                                                | Prevents shipping known vulnerable transitive code.                                                   | `composer audit`, `npm audit`                                                             | Implemented and verified                                                                                                           |
| `data-integrity-001`    | Fresh and populated schemas enforce intended foreign keys, unique indexes, task hierarchy rules, recurrence identity, and same-workspace application invariants without destructive migration shortcuts.                                    | Prevents orphans, duplicates, cycles, and data loss.                                                  | Migrations, schema integrity and supporting infrastructure tests                          | Implemented and verified                                                                                                           |
| `data-sqlite-001`       | SQLite is the only relational database; foreign keys, WAL, synchronous mode, busy timeout, checkpoint, health checks, filesystem placement, and backup behavior are explicit and tested.                                                    | Maintains concurrency and recovery safety on web/mobile.                                              | `SqliteHealthService`, command, config, SQLite docs/tests                                 | Implemented and verified                                                                                                           |
| `data-time-001`         | Canonical timestamps are stored unambiguously and user-facing date/time boundaries use the selected IANA timezone and locale.                                                                                                               | Prevents due-date, recurrence, reminder, and calendar drift.                                          | preference enum/casts, shared formatters, query objects, localization/recurrence tests    | Implemented and verified                                                                                                           |
| `perf-query-001`        | Critical dashboard, task, project, calendar, activity, and notification pages have bounded query counts, eager-loaded relationships, deterministic pagination, and no model/resource/view query side effects.                               | Prevents N+1 and unbounded memory while preserving isolation.                                         | Query objects and `PageQueryBudgetTest.php`                                               | Implemented and verified                                                                                                           |
| `perf-assets-001`       | Production CSS/JS builds succeed, Tailwind sources are discoverable, chunks are reviewable, and substantial asset growth is compared with baseline.                                                                                         | Controls initial load and missing-style regressions.                                                  | Vite/Tailwind config, `npm run build`, recorded asset measurements                        | Implemented and verified                                                                                                           |
